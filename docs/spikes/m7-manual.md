# M7 手工验收 — 语音修改（Mac 最短）

**目标：** 第二快捷键录修改指令 → 文本 AI 改草稿；未配置 AI 时不破坏原文。

## 前置

```bash
cd apps/luozi
npm run install:macos-app
```

- 草稿里先有一段文字（继续说或粘贴）
- 托盘：**配置文本 AI Key…**（可用 Groq）→ **同意文本 AI 上传…**
- 开发种子：`export LUOZI_TEXT_AI_API_KEY=...`（或复用 `LUOZI_GROQ_API_KEY`）

## A. 第二快捷键

1. 打开语音草稿，选中一句或把光标放在某段
2. 按住 `Control+Alt+Shift+Space`（或托盘「说出修改要求」）说：「改简洁一点」
3. HUD「说修改要求…」→「正在修改…」→「已修改」或确认对话框
4. 草稿对应范围被替换；撤销可用

## B. 空草稿

1. 清空草稿后触发语音修改  
2. 若 10 分钟内有最近落字 → 载入后再录；否则提示「先说一段或粘贴文字」

## C. 高风险确认

1. 原文含数字（如 `12800`），指令不要提改数字  
2. 若 AI 丢掉数字 → 弹确认；取消后正文不变

## D. 未配置

1. 无 Key / 未同意时触发修改  
2. HUD「请先配置并同意文本 AI」；正文不变

## 明确不测

- 疑似词波浪线、完整 diff sheet、语音说「应用/取消」、设置页、快捷落字自动 AI
