# Security Policy

## Supported versions

No public release yet. Treat all builds as experimental.

## Reporting a vulnerability

Please open a private security advisory on the eventual GitHub repository, or contact the maintainer directly. Do not file public issues for credential or injection risks.

## Product rules (already in design)

- Do not log password / secure-field contents
- Do not ship API keys in the repository
- Cloud ASR requires explicit per-provider authorization (future milestone)
