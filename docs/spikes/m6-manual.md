# M6 手工验收 — 单草稿工作台

**目标：** 不配置文本 AI 也能完成「说 / 粘贴 → 编辑 → 恢复 → 复制」。

## A. 打开与编辑

1. 托盘 **打开语音草稿**
2. 直接打字 / 粘贴 → 约 1s 后提示「已自动保存」
3. 关闭窗口（隐藏到托盘）→ 再打开，正文仍在

## B. 撤销 / 重做 / 复制 / 清空

1. 多改几次 → 撤销 / 重做可用
2. 复制 → 剪贴板为纯文本
3. 清空 → 确认后为空；恢复文件同步清空

## C. 语音写入草稿

1. 工作台保持焦点，按住 `Control+Alt+Space` 说话
2. HUD「已写入草稿」；正文出现转写
3. 切到备忘录再说话 → 仍走外部落字 / 剪贴板（不进草稿）

## D. 最近落字

1. 在外部 App 成功落字一次
2. 打开空草稿 → **载入最近落字**（10 分钟内）
