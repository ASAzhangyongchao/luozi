# 落字 · 如何使用（新手教程窗）设计

**日期：** 2026-07-27  
**状态：** 待实现  
**范围：** Mac-first；托盘菜单按需打开独立教程窗

## 目标

在菜单栏 / header 托盘图标的右键菜单中增加 **「如何使用…」**，点击后打开独立窗口，展示分章节的新手教程，让用户不读 README 也能完成「权限 → 说话 → 草稿/落字 → 设置」闭环。

## 已确认决策

| 项 | 选择 |
|---|---|
| 形态 | 独立小窗（不塞进设置窗、不用遮罩层） |
| 内容 | 分章节可翻（左侧目录） |
| 入口时机 | 仅托盘菜单按需打开（不做首次自动弹、不做版本更新弹） |
| 实现路线 | 镜像设置窗：静态 HTML + 轻量 TS，文案写死 |

## 非目标（本轮不做）

- 首次启动 / 版本更新后自动弹出
- Markdown 驱动或从 `docs/` 运行时渲染
- 快捷键动态读取当前注册值（文案写默认组合 + 注明「以设置页为准」）
- 教程内直接改权限 / 录制改键
- Windows / Linux 专项适配（跟随现有设置窗能力即可）

## 架构

### 窗口

- **label：** `guide`
- **标题：** `落字 · 如何使用`
- **URL：** `guide.html`
- **尺寸：** 约 `720 × 560`（与设置窗同量级，可略宽以利阅读）
- **默认：** `visible: false`，`skipTaskbar: true`
- **关闭行为：** `CloseRequested` → `prevent_close` + `hide`（与 `main` / `settings` 一致，不退出 App）
- **背景色：** 启动时设为与设置窗相同的冰白，避免暗角

### 托盘

- 在「设置…」上方增加菜单项：`如何使用…`（id: `guide`）
- 事件：`show_guide(app)` → `get_webview_window("guide")` → `show` + `set_focus`
- 重复点击：同一窗口前置（不新建）

### 前端文件

| 文件 | 职责 |
|---|---|
| `guide.html` | 壳：左 nav + 右 sections + 页脚「打开设置…」 |
| `src/guide.ts` | 章节切换；调用打开设置（`invoke` 或复用已有 settings 命令） |
| `src/styles-settings.css`（复用/轻扩） | 与设置窗同一视觉 token；必要时加 `.guide-*` 阅读排版类 |
| `vite.config.ts` | 多页入口增加 `guide` |
| `src-tauri/tauri.conf.json` | 登记 `guide` 窗口 |
| `src-tauri/capabilities/*.json` | `windows` 列表加入 `guide` |
| `src-tauri/src/lib.rs` | `show_guide`、托盘菜单、关窗 hide、背景色 |

### 与设置窗关系

- 教程页脚常驻 **「打开设置…」** → 调用现有 `show_settings(app, Some("general"))`（或等价 IPC）
- 教程不复制设置逻辑；只说明概念并跳转

## 章节内容大纲

默认打开 **快速开始**。

### 1. 快速开始

1. 将应用装到 `/Applications`（开发可用 `npm run install:macos-app`）
2. 菜单栏出现落字托盘图标；**右键**打开菜单（左键暂不作为产品入口）
3. 在「设置 → 权限」开启麦克风与辅助功能
4. 按住默认快捷键说话，松手后转写
5. 若语音草稿窗在前台且有焦点 → 写入草稿；否则尝试 AX 落字，失败则剪贴板

### 2. 快捷键

- 按住 `Control+Alt+Space`：语音输入（落字 / 草稿）
- 按住 `Control+Alt+Shift+Space`：说出修改要求（改草稿）
- `Escape`：取消当前录音 / 会话
- 模式为 **按住说话，松手处理**
- 文案注明：若你在设置里改过键，**以设置页显示为准**（本教程写的是默认值）

### 3. 语音草稿

- 托盘「打开语音草稿」
- 焦点在草稿时，语音结果写入正文；约 1s 自动保存；关窗隐藏后仍保留
- 支持撤销 / 重做 / 复制纯文本 / 清空（清空需确认）
- 空草稿时可「载入最近落字」（短时窗口内）

### 4. 说出修改

- 草稿需已有内容
- 按住修改快捷键，口头说修改要求；松手后文本 AI 改写
- 需单独配置文本 AI Key，并同意上传正文
- 结果与失败提示看 HUD / 草稿状态

### 5. 设置与权限

- 引擎模式：自动 / 仅本地 / 仅云端
- 本地模型可托盘「下载推荐模型…」；云端 ASR 与文本 AI **分项** Key + 同意
- 支持的厂商以当前设置为准（含 Groq / 千问 / 豆包 / 小米等已接入项）
- 权限：麦克风录音；辅助功能用于向其他 App 插入文字
- ad-hoc 重装后辅助功能可能需关掉再打开一次

### 6. 常见问题

- 辅助功能显示未生效 → 系统设置里检查，重装后开关一次
- 没有本地模型 → 可配云端 ASR，或先下载推荐模型
- 未授权辅助功能 → 降级剪贴板，需手动粘贴
- 当前没有首次引导；随时从托盘「如何使用…」打开本窗
- 尚无正式 Release 安装包 / 公证时，按开发安装路径说明即可

## 交互细节

- 左 nav：`nav-item` 切换对应 `section-*`，仅一节可见
- 页脚常驻「打开设置…」
- 无需持久化「上次阅读章节」（每次默认快速开始即可；可选记住，非必须）
- 无网络请求；无 invoke 依赖亦可打开正文（打开设置除外）

## 验收标准

1. 托盘菜单出现「如何使用…」，点击打开独立窗，标题为「落字 · 如何使用」
2. 六个章节可切换，文案与当前产品能力一致，无把未做功能写成已支持
3. 「打开设置…」能打开设置窗
4. 关闭教程窗不退出 App；再次从菜单打开仍可用
5. 不影响草稿、设置、按住说话主路径

## 测试计划

- 手工：按上文验收 1–5（可用 `docs/spikes/` 增补短清单，实现时再写）
- 回归：托盘其他菜单项、设置关窗 hide、录音快捷键仍正常
- 构建：`npm run build`；capabilities 含 `guide` 后 `tauri` 能加载该窗

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 教程快捷键与用户自定义不一致 | 写默认值 +「以设置页为准」 |
| 文案落后于功能 | 与 README / CHANGELOG 同步；实现后更新 README「明确还没有」里首次引导相关表述为「菜单内教程已提供」 |
| 多一窗增加 capabilities 遗漏 | 改 `default.json` / `desktop.json` 时一并加 `guide` |
