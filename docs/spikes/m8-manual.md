# M8 手工验收 — 设置壳（Mac 最短）

**目标：** 托盘能打开正式设置 / 关于；ASR 与文本 AI 可在设置里配置；练习窗不再当产品入口。

## 前置

```bash
cd apps/luozi
npm run install:macos-app
```

## A. 入口

1. 托盘 **设置…** → 打开「落字 · 设置」，默认「通用」
2. 托盘 **关于落字** → 设置窗切到「关于」
3. 托盘 **检查权限…** → 切到「权限」
4. 托盘 **开发 Spike…** → 草稿窗显示 Spike 面板（非正式功能）

## B. 语音与 AI

1. 「切换模式」循环：自动 / 仅本地 / 仅云端
2. 「配置 Key…」「同意上传…」对 ASR 与文本 AI 分别可用
3. 状态文案随就绪情况变化

## C. 快捷键 / 权限 / 关于

1. 快捷键页只读展示两组组合键，可复制
2. 权限页可打开系统麦克风 / 辅助功能设置
3. 关于页：版本号、开源仓库、查看更新（浏览器打开 Releases）

## 明确不测

- 开机启动、快捷键录制改键、首次引导、液态玻璃精修、Release 安装包
